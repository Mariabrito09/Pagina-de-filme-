## 📄 Sobre o Projeto

Este repositório contém o código-fonte de uma página web estática construída em HTML5 dedicada ao filme **Toy Story 5**. O projeto foi elaborado com o intuito de aplicar conceitos essenciais de estruturação web, semântica de tags, inserção de mídias e hiperlinks.

## 🎯 Objetivo

O objetivo principal deste projeto é exercitar a marcação HTML5 estruturada, organizando elementos visuais e textuais tais como:
1. Cabeçalhos hierárquicos (`<h1>`, `<h2>`).
2. Imagens com atributos de acessibilidade (`<img>`, `alt`).
3. Blocos de texto formatados e sinopse do filme (`<p>`).
4. Links de navegação externa para fontes de referência (`<a>`).

## 🌐 Breve Descrição da Página

A página web desenvolvida apresenta uma interface limpa e focada em dados sobre **Toy Story 5**:

- **Cabeçalho Principal:** Apresenta o título em destaque.
- **Mídia:** Imagem promocional redimensionada do filme.
- **Ficha Técnica:** Exibe ano de produção, diretor, duração, faixa etária, gênero e país de origem.
- **Sinopse:** Texto resumido abordando o dilema dos brinquedos clássicos frente ao avanço dos dispositivos digitais (o tablet *Lilypad*) e o retorno de Woody para auxiliar a turma liderada por Jessie.
- **Navegação Externa:** Botão/link hipertexto direcionando o usuário para o artigo completo sobre o filme na Wikipédia.
